Build the APK (no coding needed):
1. Install Android Studio. File > Open > select the PadLink folder. Accept "Gradle sync".
2. Build > Build Bitmap(s)/APK(s) > Build APK(s). The file is app/build/outputs/apk/debug/app-debug.apk
3. Copy it to the phone and install it (allow "install unknown apps").
Use: open PAD LINK, type the PS3 IP, press CONNECT. Landscape only.
Protocol (UDP port 8080): HELLO -> reply OK ; "E,<code>,1|0" ; "S,L3|R3,<x>,<y>"
